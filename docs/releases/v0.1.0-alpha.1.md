The first alpha of **Dogubako** (道具箱, "toolbox"): 249 small tools for your
files in one app. Convert images, shrink PDFs, trim video, transcribe speech,
format JSON and more, on your own computer or on a server you host. Free and
open source under the AGPL-3.0-or-later.

This is an alpha for testers. Things will break, and settings or file formats
may change before 1.0. Please [report problems](https://github.com/Mischa-dev/Dogubako/issues).

## Opening the app

Open the DMG and drag Dogubako to Applications.

<!-- Variant B: unsigned. Keep this if there was no Developer ID at release time. -->
This alpha is not signed with an Apple Developer ID yet, so macOS blocks it the
first time:

1. Open the DMG and drag Dogubako to Applications.
2. Open Dogubako. macOS says it can't verify the developer. Click **Done**.
3. Open **System Settings → Privacy & Security**, scroll to the message about
   Dogubako and click **Open Anyway**, then confirm with your password.

You only need to do this once.

## What's in it

- **249 tools in 12 categories:** images, video, audio, speech, PDF and
  documents, files, text, developer, data, network, design, system.
- **Five ways in, one engine:** the desktop app, a self-hosted web app, the
  `dogubako` CLI, an HTTP API and an MCP server for AI agents. They all run the
  same tool code with the same checks.
- **Engines managed by the app (macOS).** FFmpeg, qpdf, Poppler, ExifTool and
  7-Zip are inside the app. ImageMagick, Tesseract, Ghostscript, Pandoc,
  whisper.cpp and Real-ESRGAN download into the app's own folder the first time
  a tool needs them, at versions tested with this release. Nothing is installed
  system-wide.
- **Plain words (opt-in).** Turn it on in Settings, pick a model (OpenAI,
  Anthropic, OpenRouter, Ollama, LM Studio, or any compatible endpoint) and
  type what you want done. It runs or opens the right tools, and asks before
  any step that uses the network, writes to a folder or changes files. It's off
  by default and sends nothing until you set it up.
- **Host it once.** The Docker image includes every engine. Give each AI agent
  its own scoped token: an image bot may resize and blur, a media bot may
  transcode, and neither sees the other's files.

## Privacy

Where your files go depends on how you run Dogubako. With the desktop app,
they're processed on your Mac and never uploaded. With a hosted Dogubako, they
go to that server and are processed there, so use a server you trust. The app
needs no account for desktop use and has no telemetry. Network tools (DNS, HTTP headers, TLS
and so on) contact the targets you give them. Model downloads, on-demand engine
downloads and plain-words mode need a connection, and only happen when you ask.

## Known issues

- **Apple silicon only.** Managed engines come from Homebrew, which no longer
  builds for Intel Macs.
- **Some tools need engines the app doesn't manage yet:** LibreOffice (Office
  conversions), Piper (text to speech) and rembg (background removal). Install
  them yourself; **Settings → Dependencies** shows what's missing and how.
  Piper's macOS release is currently broken upstream.
- **ExifTool** uses the Perl that ships with macOS.
- The CLI binaries don't include engines; they use what's installed on the
  system (`dogubako deps` lists what's missing).
