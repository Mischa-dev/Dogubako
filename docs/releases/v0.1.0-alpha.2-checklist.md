version bump are ready on this branch. Nothing has been tagged, published or

## 3. The go (Mischa only)

1. Tag: `git tag -a v0.1.0-alpha.2 -m "Dogubako 0.1.0-alpha.2" && git push origin v0.1.0-alpha.2`.
   The Release workflow builds the DMG, engine packs, the three CLI binaries,
   the homelab image, the engine sources and `SHA256SUMS.txt` into a **draft**
   release.
2. Check the draft:
   - [ ] All assets are there: DMG, engine packs + `packs.json`, three CLIs,
         `engine-sources-0.1.0-alpha.2.tar`, `SHA256SUMS.txt`.
   - [ ] The DMG opens on a clean Mac, and an on-demand engine downloads (try OCR).
   - [ ] The Linux CLI from the draft runs `--help` on Debian 13
         (`docker run --rm -v "$PWD:/b" debian:13-slim /b/dogubako-x86_64-unknown-linux-gnu --help`).
   - [ ] The Windows and macOS CLIs print `0.1.0-alpha.2` from `--version`.
   - [ ] `docker run ghcr.io/mischa-dev/dogubako:0.1.0-alpha.2` becomes healthy.
   - [ ] `sha256sum -c SHA256SUMS.txt` passes.
3. Paste `docs/releases/v0.1.0-alpha.2.md` (below its line) into the release
   body, tick **Set as a pre-release**, and publish.
4. Deploy the website: Actions → Website → Run workflow with release
   `v0.1.0-alpha.2` and `deploy` ticked. Before that, update the copy that
   names alpha.1 (README, `website/`, `site/.../start/install.md` and
   `start/alpha.md`, `self-hosting/docker.md`).
5. Mark the milestone done in the workspace and announce.

## Rollback

- Bad release: mark it as a draft again, fix, and tag `v0.1.0-alpha.3`. Don't
  move a published tag.
- Bad website deploy: Cloudflare Pages → dogubako-website → Deployments →
  roll back to the previous one.
