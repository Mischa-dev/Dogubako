## One toolbox, every way you work

<CardGrid>
  <Card title="Desktop app" icon="laptop">
    A native app for macOS, Windows and Linux. Drop a file in, pick what should happen, done. No account, no server, no telemetry.
  </Card>
  <Card title="Self-hosted web app" icon="seti:docker">
    Run one server at home or on a VPS with all the heavy engines installed, and use it from any browser, including your phone.
  </Card>
  <Card title="Command line" icon="seti:shell">
    Every tool is a `dogubako` command with typed options, piping, JSON output and meaningful exit codes.
  </Card>
  <Card title="HTTP API and MCP" icon="puzzle">
    Automate with a generated OpenAPI document, or give each AI agent its own scoped token and a curated set of tools.
  </Card>
</CardGrid>

## Why Dogubako

<CardGrid>
  <Card title="Local first" icon="approve-check">
    Files are processed on your device or your own server. Nothing is uploaded to a third party.
  </Card>
  <Card title="Built on mature engines" icon="rocket">
    FFmpeg, ImageMagick, libvips, ExifTool, qpdf, Poppler, Ghostscript, Tesseract, whisper.cpp and more, plus fast native Rust tools for everything that doesn't need them.
  </Card>
  <Card title="One implementation" icon="random">
    Each tool is described once. The app, CLI, API, OpenAPI schema and MCP tools are all generated from that description and run through the same engine.
  </Card>
  <Card title="Secure by construction" icon="warning">
    No shell is ever used, external programs run with time and resource limits, files are owner-checked and network tools are SSRF-guarded.
  </Card>
</CardGrid>
