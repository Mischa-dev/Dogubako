**Transcribe Video URL** (`speech.transcribe_url`, `dogubako speech transcribe-url <url>`)
turns the link to a video into the words that were actually said. Paste the
page URL of one video; you get the whole transcript with timestamps, not a
summary.

## Where the text comes from

| Source | When | Labelled |
|---|---|---|
| Captions published with the video | The site has a caption track in the language you asked for | `captions` |
| Captions auto-generated by the site | No published track, and **Allow auto-generated captions** is on (YouTube's automatic captions) | `auto_captions` |
| Whisper, on your computer | **Source** is *Whisper only*, or the video has no captions at all | `whisper` |

**Language** is `auto` by default: the language spoken in the video. Enter a
code such as `de` or `pt-BR` to pick another caption track; if the video has
no captions in it, the error lists the languages it does have. A track the
site machine-translated into another language comes with a warning, because it
is not what was said.

Every result starts with the source URL and site, the language, which of the
three sources the text came from, and the duration. The JSON export and the
`data` of an API or MCP call carry the same fields (`source`, `transcript`,
`available_captions`, `segments`). Choose any of text, SRT, WebVTT, JSON and
Markdown under **Formats**.

## Setup

- **yt-dlp** reads the video page and fetches captions and audio. Install it
  with your package manager (`brew install yt-dlp`, `winget install yt-dlp`,
  `pipx install yt-dlp`) and keep it current (`yt-dlp -U`), because sites
  change often and old versions stop working.
- **Whisper transcription** (for videos without captions) also needs
  whisper.cpp and FFmpeg (Settings → Engines) and a Whisper model
  (Settings → Models). Captions alone need neither.
- The tool needs the **network** permission.
- All of yt-dlp's traffic, redirects and media downloads included, goes
  through Dogubako's network policy. On a server that allows only public
  addresses, a video that points at a private address fails with a
  permission error. Media is fetched over HTTP(S) or HLS only.

## Supported sites

Anything yt-dlp has an extractor for: see its
[list of supported sites](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md).
Dogubako turns off yt-dlp's generic extractor, so the link has to be a page on
one of those sites, not a direct `.mp4` (download that and use **Transcribe
Audio / Video** instead). Tested:

- **YouTube**: published and auto-generated captions in every listed
  language. YouTube often asks servers and VPN users to "confirm you're not a
  bot"; add a cookies file (below). yt-dlp also needs a JavaScript runtime such
  as [Deno](https://deno.com/) for some YouTube formats.
- **TED** talks: published captions in many languages.
- **Vimeo** and other sites: captions when the uploader added them, otherwise
  Whisper. Many Vimeo videos need a signed-in account.

## Limitations

- **Signed-in, private, members-only and age-restricted videos** need your
  browser's cookies: export them for the site to a Netscape `cookies.txt` file
  (for example with a "Get cookies.txt" browser extension) and choose it under
  **Cookies**. Dogubako passes a copy to yt-dlp and never changes your file.
- **Playlists and channels** are not transcribed; give the URL of one video.
- **Live streams and premieres** can be transcribed once they have ended.
- **Long videos**: captions of any length work. Whisper only downloads and
  transcribes videos up to **Max minutes** (240 by default); transcription
  takes roughly real time on the small models, longer on large ones.
- **Geo-restricted** videos fail with a message saying so.
- Auto-generated captions are only as good as the site's speech recognition;
  Whisper with a larger model is often more accurate.
