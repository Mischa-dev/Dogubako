On macOS use <kbd>⌘</kbd>; on Windows and Linux use <kbd>Ctrl</kbd>. Single-key
shortcuts such as <kbd>T</kbd> and <kbd>/</kbd> work whenever you are not typing
in a field.

## Everywhere

| Keys | Action |
|---|---|
| <kbd>⌘</kbd> <kbd>K</kbd> | Open or close search |
| <kbd>/</kbd> | Open search |
| <kbd>T</kbd> | Open or close the Tools menu |
| <kbd>⌘</kbd> <kbd>\\</kbd> | Hide or show the sidebar |
| <kbd>Alt</kbd> <kbd>1</kbd> … <kbd>Alt</kbd> <kbd>9</kbd> | Open pinned tool 1 to 9 |
| <kbd>Esc</kbd> | Close the open menu, sheet or drawer |

## Search

| Keys | Action |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> | Move through results |
| <kbd>Page Up</kbd> <kbd>Page Down</kbd> | Jump eight results |
| <kbd>Enter</kbd> | Open the selected result |
| <kbd>Esc</kbd> | Close search |

## Drop screen

| Keys | Action |
|---|---|
| <kbd>1</kbd> … <kbd>9</kbd> | Open the numbered suggestion (when nothing is typed) |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move through the suggestions |
| <kbd>Enter</kbd> | Open the selected tool |
| <kbd>Esc</kbd> | Clear what you typed, or go back |

## Tool page

| Keys | Action |
|---|---|
| <kbd>⌘</kbd> <kbd>Enter</kbd> | Run the tool |
