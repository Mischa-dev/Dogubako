道具箱dōgu-bako, “toolbox”

Every file job, in one box.

Convert a photo, shrink a PDF, transcribe an interview, format JSON. Dogubako is 249 tools in one free, open-source app that runs on your own machine. No uploads to sites you don’t know, no account, no telemetry.

    Local-first

    Your files stay on your machine.

    Nothing leaves your machine unless you host Dogubako yourself. The desktop app needs no account and sends no telemetry. The engines that do the work are in the box.

    Runs here
    Every tool runs on your own computer, using mature open-source engines and native Rust code.
    No shell
    External programs get exact arguments, timeouts and resource limits. A shell is never used.
    Network
    Only the Network & Web tools go online, because that is their job. On a server they are guarded against SSRF.
    Open
    AGPL-3.0-or-later. Every line is on GitHub.

    Self-hosting & agents

    Host it once.
    One key per agent.

    Run Dogubako on a home server or a VPS with all the heavy engines installed. The web UI works on phones. Every person and every agent gets an account that can use exactly the tools you allow, and nothing else.

    $ docker compose up -d --build
    $ dogubako users create media-bot --role agent \
    --allow 'video.*' --allow 'speech.*'
$ dogubako tokens create --user media-bot --name laptop-agent
