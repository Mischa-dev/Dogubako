道具箱·dōgu-bako, “toolbox”

249 tools for your files, in one box.

Convert a photo, merge PDFs, trim a video, transcribe an interview, format some JSON. Dogubako does the small file jobs you’d normally hand to a random website, on your own computer. Free and open source.

Local-first

Your files stay on your bench.

The desktop app needs no account and sends nothing anywhere. Host it yourself and your files only travel to a machine you own.

No shell
External programs run directly, with timeouts, resource limits and optional bubblewrap sandboxing.
Owner-checked files
Files are addressed by id and checked against their owner on every request. Archives are guarded against bombs and path tricks.
Guarded network tools
On a shared server, tools that fetch URLs refuse to reach into your private network by default, and every action goes to an audit log.
Open source
GNU AGPL v3.0 or later. No telemetry, no paywalls, and all of the code is there to read.

Built on FFmpeg · ImageMagick · libvips · ExifTool · qpdf · Poppler · Ghostscript · Tesseract · whisper.cpp · Piper · LibreOffice · Pandoc · 7-Zip and native Rust for everything that doesn’t need them.

Self-hosting and agents

Host it once. Give each agent its own key.

Run Dogubako on a home server, a NAS or a VPS with the heavy engines installed once, and open it from any browser on your network, phones included. Then hand each AI agent a scoped token: an image bot may resize and blur, a media bot may transcode and transcribe. Neither can see the other’s files or touch your system tools.

  • media-botvideo.* · speech.*
  • image-botimage.resize · image.face_blur

Self-hosting guide Agents and MCP

server
# on the server
$ docker compose up -d --build
$ docker compose logs dogubako | grep "Setup token"

# one account per agent, limited to its tools
$ dogubako users create media-bot --role agent \
    --allow 'video.*' --allow 'speech.*'
$ dogubako tokens create --user media-bot --name laptop

# or, on your own machine, for a local agent
$ claude mcp add dogubako -- \
    dogubako mcp serve --discovery compact
