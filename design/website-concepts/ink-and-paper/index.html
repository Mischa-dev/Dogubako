Dogubako

All the little tools, in one box.

Dogubako is 249 free tools for the jobs you’d otherwise open a website for: convert a photo, shrink a PDF, transcribe an interview, tidy some JSON. Every one of them runs on your own machine.

Get the alpha Read the docs
  • 249 tools in 12 categories
  • App, CLI, HTTP API, MCP
  • macOS, Windows, Linux, or your server
  • No account. No telemetry.
  • AGPL-3.0-or-later

Dogubako draws each file as what it is: a photo as a print, a PDF as a stack of pages, a video as film, audio as a waveform. Then it offers the tools that fit, numbered one to four. Unroll the scroll.

Four ways in

One tool, written once, opened four ways.

Every tool is described once. The app’s form, the command, the HTTP endpoint and the MCP tool are all generated from that description and run on the same engine, so they behave the same everywhere.

一

The app

macOS · Windows · Linux
Drop a file, or say what you need

2.4 MB

  2. 2Convert Images

Drop a file, pick a number. On a server you host, the same app works in any browser, phones included.

二

The command line

dogubako
$ dogubako image compress \
    shot.png -o shot-small.png

$ dogubako tools search pdf

$ echo '{"b":1}' \
    | dogubako dev json

Every tool is a subcommand with generated --help. Pipes in, files out, --json when a script is reading.

三

The HTTP API

/api/v1
# upload, get an id back
PUT /api/v1/files/raw?name=dune.jpg
# {"id": "f_…"}

# run the tool on it
POST /api/v1/tools/image.compress/run
{"params": {"input": ["f_…"],
            "quality": 75},
 "wait_seconds": 60}

Upload, run, download. An OpenAPI document with a typed schema for every tool is generated too.

3
四

MCP, for agents

stdio · HTTP
$ claude mcp add dogubako -- \
    dogubako mcp serve \
    --discovery compact

# the agent searches, then runs
dogubako_search_tools
dogubako_run_tool
{"tool": "image.compress",
 "arguments": {…}}

Compact discovery hands an agent a few meta-tools instead of all 249: search, describe, run, check a job. Its context stays clear.

4

Local-first

Your files stay on your desk.

Most “free online” converters work by uploading your file to someone else’s computer. Dogubako brings the tools to yours instead.

Nothing is uploaded
The desktop app runs every tool on your computer, against your files. If you host Dogubako yourself, files go to your server and nowhere else.
No account, no telemetry
The desktop app doesn’t ask who you are and doesn’t report what you do with it.
Careful about what it runs
No shell is ever used. External programs run with timeouts and resource limits, network tools are guarded against reaching places they shouldn’t, and a server keeps an audit log.
Free and open source
AGPL-3.0-or-later. Read the code, build it yourself, keep it as long as you like.

Self-hosting and agents

Host it once. Give each agent its own key.

Run Dogubako on a home server or a small VPS and use it from any browser, your phone included. AI agents connect over MCP or the HTTP API with a token that opens only the tools you allow, and only their own files.

# on the server
$ docker compose up -d --build

# an agent that may only touch video and speech
$ dogubako users create media-bot --role agent \
    --allow 'video.*' --allow 'speech.*'
$ dogubako tokens create --user media-bot --name laptop
